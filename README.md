# AI CONTENT STUDIA

Чистая версия проекта для публикации на Vercel.

## Быстрая публикация

1. Распакуйте архив.
2. Загрузите папку в новый репозиторий GitHub.
3. В Vercel нажмите **Add New → Project**.
4. Выберите репозиторий.
5. Framework Preset: **Next.js**.
6. Нажмите **Deploy**.

Дополнительные переменные и базы данных не требуются.

## Локальный запуск

```bash
npm install
npm run dev
```
